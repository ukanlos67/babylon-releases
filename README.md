# Babylon: installatori

Qui ci sono soltanto i file d’installazione di Babylon per Windows, uno per
ogni versione. Il codice non è qui.

Per installare, apri l’ultima versione in
[Releases](https://github.com/ukanlos67/babylon-releases/releases/latest) e
scarica `Babylon_…_x64-setup.exe`.

Dopo la prima installazione Babylon si aggiorna da solo: quando esce una
versione nuova compare un avviso con il pulsante «Aggiorna». Ogni installatore
è firmato, e Babylon installa soltanto i file con la firma giusta.
